# Introdução e Instalação

Go é uma linguagem de programação focada em simplicidade e eficiência, ideal para sistemas escaláveis e concorrência.

## O que é Go?
Criada pelo Google, Go combina a performance de linguagens compiladas com a facilidade de leitura de linguagens modernas.

## Como Instalar
1. Vá ao site oficial: [go.dev/dl](https://go.dev/dl/).
2. Baixe a versão para seu sistema (Windows, Linux ou macOS).
3. Após instalar, abra seu terminal e digite:
   ```bash
   go version
